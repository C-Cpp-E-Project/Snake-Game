## Snake Game 🐍

A classic *Snake Game* built with Arduino and simulated using Proteus. The game features a dynamic snake moving on an 8x8 LED Matrix, live score tracking on an LCD display, and real-time keyboard control via Serial Monitor.

### Features
* 🐍 Classic snake movements on an 8x8 LED Matrix.
* ⚡ Real-time hardware simulation with responsive keyboard controls (`W`, `A`, `S`, `D`).

### Files Included
* `1.ino` - The core Arduino source code.
* `1.pdsprj` - The Proteus simulation design file.
